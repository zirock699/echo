# Concept B · Rehearsal desk

[Open the prototype](index.html) · [Compare both concepts](../index.html)

Echo opens with a situation that invites one short reply. **Talk now** opens the cue in one interaction. A prepared listener can open **Move a deadline** at the saved phrase, then deliberately choose Play. **Pick a speaking drill** offers a focused variation on the same job. Rehearse, Library and Journal handle starting, finding and returning without asking for a learning plan.

| Journey | What to try |
| --- | --- |
| Speak from a situation | Choose **Talk now**, say the update in your own words, then leave or make a private example note. |
| Continue a reference | Open **Move a deadline**, listen or replay, use the queue and try a different message. The cue pauses the reference and returns to the same place. Ordinary browsing keeps the audio and the compact controls available. |
| Find or prepare a reference | Search for `deadline`, use Favourite, open **Work conversations**, or add a text reference in this tab. |
| Listen back | In the player, open **Record and compare**, then **Start demo recording** and **Stop and listen back**. The paired local samples have separate playback controls. |
| Finish and return | Use **Finish this rehearsal** in player settings at any phrase, or finish from a cue or comparison. Save an optional note, then reopen it from Journal. |

The review includes [an empty library](index.html?case=empty#rehearse) and [an unavailable reference](index.html?case=unavailable#practice/deadline). Echo’s text cue stays usable in both cases. The prototype uses fictional lesson and rehearsal material, authored synthetic MP3 clips and a bundled example take. The example waveforms are derived from these tracks. Favourites, practice selections, added text and Journal notes live in this tab’s memory.

The design uses warm paper for the desk, ink blue for the listening stage and yellow for primary actions. Bricolage Grotesque directs attention to the current task. Instrument Sans supports controls and reading. Both fonts are locally bundled with their OFL notices. The generated portrait belongs to the first rehearsal and the room photograph anchors sample reference artwork. The artifacts use shared buttons, lesson rows, track controls, native dialogs, a mobile navigation bar and a desktop queue at wider widths.

I inspected the current app and the concept in Chromium 156. I opened the final 390 × 844 Home, 430 × 932 player, 768 × 1024 Library, 1440 × 900 comparison and 844 × 390 Home. Interaction checks also covered 320 × 568. Tests exercised actual local audio, keyboard entry and return focus, browser Back and Forward, compact playback, hit targets, a distinct transfer, unavailable text navigation and Journal return.
