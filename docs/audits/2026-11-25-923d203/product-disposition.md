# Preserve, improve and consolidate

The defining workflow is hearing the intended phrase, repeating it, controlling another listen and returning later with progress intact. It works well enough on local native audio to merit focused repairs. The [product specialist](specialists/product-strategist.md) traces current entry points and scores feature value. [Current player decisions](../../PLAYER_DECISIONS.md) take precedence where the original prompt differs.

| Disposition | Capabilities and constraints | Evidence and decision |
| --- | --- | --- |
| Preserve essential | Original cue times, Continuous listening, deliberate Manual and Automatic practice, main Play/Pause/Replay, Next and marks, optional lead-in and speed, persistent media across navigation and no startup autoplay | Local native timing and prepared/resume checks support the current model. Repair mode/filter agreement and restoration without resetting deliberate user choices. |
| Preserve essential | Manual captions, ZIP/audio import, stable lesson and phrase identity, edit/regroup/Undo, explicit conflict and owner-scoped cloud storage | Existing import/recovery and SQLite tests support the approach. First entry, valid VTT, restore and media retention need targeted corrections before new import formats. |
| Preserve high-value support | Resume, saved selections and Difficult review, transparent progress/history, search, Library/courses and collections | These help repeat practice over time. Fix Continue and distinguish position, listening and deliberate practice before adding metrics. Restrict empty review to a valid selection. |
| Preserve targeted support | Built-in British IPA, word actions and optional overrides, on-demand comparison and device-local attempts | Browser fixtures verify IPA and override saves. A starter lexicon is a limit. Echo Mirror is useful as an optional listening/recording tool with actual learning benefit unmeasured. Fix original playback bounds and microphone lifecycle first. |
| Preserve secondary | Artwork, categories, favourites, view controls, optional wake lock and settings | Keep their role in finding and resuming lessons. Prioritise player clarity and interface reliability. Measure actual use before changing available controls. |
| Improve | Focus and names, light-context contrast, current phrase time, Save & practise, large-queue behavior, offline metadata boot | Small scoped changes address observed failures across user journeys. No broad redesign is justified by one audit. |
| Consolidate | Duplicate Practised/Difficult controls, divergent lesson-delete routes, duplicate logic for source bounds and capture ownership where contracts agree | Keep the underlying functionality. QA should verify equivalent access and semantics after consolidation. Legacy untimed recording and Mirror are distinct workflows until equivalence is verified. |
| Consider for removal after replacement | Broken or historical test entry points only when their useful assertions have an executable successor | Development cleanup, not feature removal. Preserve historical decision records. |

No removal of a shipped learning capability is recommended. New analytics, recording scoring, social features, content extraction and platform changes offer no demonstrated benefit against the risks in this baseline. If current external-player requirements constrain compact size, resolve it with authorised verification and a compatible UX decision.
